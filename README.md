# buttons-mk1
<!-- Short description of what your project does(3-4 senetnces)-->
A small project I have been working on since yesterday. I made various buttons that I hope to use in the future. Creating these buttons saves me the trouble of creating them again in the future. 

## Technologies
<!-- Technologies you used -->
- HTML
- CSS
- _Visual Studio Code_

## Features
<!-- What the users can do -->
All you have to do is just hover over any of the buttons that catch your eye. There are some buttons you can click on while other buttons have various hover effects. 

## The Process
<!-- The process of how I build it -->
The purpose of this project was to build various buttons for me to use in future projects. I built each button with a different purpose and used z-index to create smooth animations. In addition I also used before and after effcts. 


## What I learned
<!-- In 2-3 sentences tell everyone what you learned -->
I learned about the exsistence of remixicon.com. Remix allows me to use various icons that are available for me to customize or use. I also learned about the use of Z-index.
